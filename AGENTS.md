## Battlezone runtime and validation

Battlezone is a native winit/wgpu window application. The Kitty renderer and terminal keyboard backend have been removed. These repo-specific instructions supersede older terminal smoke-test notes in shared guidance.

Run `make ci` for formatting, all-target tests, and warnings-as-errors Clippy. Run interactive smoke tests in a graphical desktop session with `cargo run --release`: verify visible attract rendering, Enter starting gameplay, held-key releases, resize handling, focus-loss input clearing, and Escape or window-close exit. A PTY or successful process startup alone does not prove GPU presentation.

The published Homebrew formula pins the wgpu source commit; its optional HEAD build follows `develop`. Keep the README installation commands and tap formula aligned when changing release or branch selection. Use `battlezone --help` and `battlezone --version` for display-free installed-command checks.

Documentation media is generated by `make readme-media` from `examples/generate_readme_media.rs`. Update that maintained source before regenerating PNG/GIF assets. Media shows game frames without terminal branding or simulated window chrome.
